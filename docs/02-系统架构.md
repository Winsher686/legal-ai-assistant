# 系统架构

## 整体架构

```
用户浏览器
    |
  Nginx（反向代理 / 静态资源）
    |
FastAPI Backend（业务服务）
    |
    |-----------------------------|
    |              |              |
RAG 检索链路   GraphRAG 链路    异步任务
    |              |              |
Milvus         Neo4j          Celery + Redis
    |              |
PostgreSQL（业务数据）
```

## 数据流

### 文档入库流程

```
上传文件 → FastAPI → 保存文件 + 写 PostgreSQL → Celery 异步任务
    → 解析（PDF/Word/TXT）→ 清洗 → 切片（章节+条款）→ Embedding
    → Milvus（向量） + Neo4j（实体关系）
```

### 问答流程

```
用户问题 → Query 理解 → Query 改写/扩展
    → 向量检索（Milvus）+ 关键词检索（BM25）→ RRF 融合 → Reranker
    → GraphRAG 查询（Neo4j）→ 上下文融合 → Prompt → LLM 生成
    → 引用绑定 → Citation Checker → 可信度评分 → 返回
```

## 技术选型理由

- **Milvus**：高维向量检索，支持亿级向量、水平扩展
- **Neo4j**：知识图谱关系查询，Cypher 多跳推理
- **混合检索**：向量理解语义 + BM25 精准匹配编号/法条
- **RRF 融合**：无需调参的多路召回融合
- **Reranker**：BGE-reranker 精排提升 Top-K 准确率
- **Citation Checker**：防止大模型幻觉，答案可追溯
